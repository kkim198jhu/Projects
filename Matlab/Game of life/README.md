# Conway’s Game of Life

Explore how a grid of live and dead cells evolves across generations. Open this folder in MATLAB and enter `Kim_problem3` to launch the GUI.

| Explore | What you’ll find |
| --- | --- |
| [GOL.m](./GOL.m) | Game of Life logic. |
| [Kim_problem3.m](./Kim_problem3.m) | GUI entry point and callbacks. |
| [Kim_problem3.fig](./Kim_problem3.fig) | GUI layout. |
| [RLE_Encoder.m](./RLE_Encoder.m) | Encode a pattern using run-length encoding. |
| [RLE_Decoder.m](./RLE_Decoder.m) | Decode an encoded pattern. |
