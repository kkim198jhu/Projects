# Computer Systems Fundamentals

The Spring 2025 systems coursework is tracked as a Git submodule. The parent repository records the course repository at a specific commit.

| Explore | What you’ll find |
| --- | --- |
| [Course repository at the recorded revision](./CSF-Spring-2025) | Follow the folder link on GitHub to inspect that revision. |

## Local checkout

From the root of Projects, populate the course folder with:

```bash
git submodule update --init --recursive -- "Assembly and C ++ extended/CSF-Spring-2025"
```
