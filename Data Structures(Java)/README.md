# Data Structures in Java

Five projects connect data structure choices to practical tasks, from searching a street graph to measuring the work performed by a sorting algorithm.

| Explore | What you’ll find |
| --- | --- |
| [Shortest paths on a street graph](./Graph%20Theory) | Find routes with Dijkstra’s algorithm on a sparse graph. |
| [Hash maps and search](./Hashmaps) | Compare separate chaining with open addressing in the context of a search engine. |
| [Heaps and ordered maps](./Heap%3ATrees) | Compare ordered-map implementations and explore a binary heap priority queue. |
| [Measuring sorting algorithms](./Lists%20and%20Sorts) | Explore how insertion, selection, bubble, and gnome sort access and modify an indexed list. |
| [Indexed list representations](./Sparse%20and%20Linked%20List) | Compare array-backed, linked, and sparse representations of the same indexed-list interface. |
