# Kyle Kim | Projects

I’m a computer science student at Johns Hopkins University with an interest in medical robotics and interactive software. This repository collects coursework and projects ranging from surgical navigation to a cooperative platformer.

For a closer look at my work, start with the tracked-pointer registration project in Computer-Integrated Surgery or explore the playable level mechanics in Let’s Face It Together.

| Explore | What you’ll find |
| --- | --- |
| [Computer-Integrated Surgery](./CIS_I_Course%20copy) | Three simulations explore how to locate a surgical tool, calibrate a robot, and align tracked measurements with a femur surface. |
| [Let’s Face It Together](./Lets-Face-It-Together) | A two-player Java platformer built around emotions. The levels pair platforming puzzles with mechanics such as wind zones, gravity switches, and breakable walls. |
| [Augmented Reality](./AR) | Tracking experiments and wall-placement prototypes explore how virtual objects can be positioned in a physical space. |
| [Computer Vision](./Computer%20Vision) | Image stitching and stereo disparity explore what can be recovered from two views of a scene. |
| [Machine Learning and Deep Learning](./MLDL) | Notebook experiments progress from implementing a classifier to segmenting surgical images and adapting VGG16 to clothing classification. |
| [C Programming](./C) | Two command-line projects work with grids of pixels and letters. |
| [C++ Programming](./C%2B%2B) | A chess game and a tree implementation illustrate two ways to organize C++ objects. |
| [Human–Computer Interaction](./HCI) | Prototype walkthroughs document heuristic evaluations at two levels of design fidelity. |
| [MATLAB](./Matlab) | A graphical implementation of Conway’s Game of Life pairs a cellular automaton with run-length encoding for patterns. |
| [Python Programming](./Python) | Two small projects use Python for text analysis and polynomial arithmetic. |
| [Data Structures in Java](./Data%20Structures%28Java%29) | Five projects connect data structure choices to practical tasks, from searching a street graph to measuring the work performed by a sorting algorithm. |
| [Computer Systems Fundamentals](./Assembly%20and%20C%20%2B%2B%20extended) | The Spring 2025 systems coursework is tracked as a Git submodule. The parent repository records the course repository at a specific commit. |
