# Let’s Face It Together

A two-player Java platformer built around emotions. The levels pair platforming puzzles with mechanics such as wind zones, gravity switches, and breakable walls.

| Explore | What you’ll find |
| --- | --- |
| [Game source](./src/main/java/com/letsfaceittogether) | Player logic, emotion states, screen transitions, and save handling. |
| [Levels and menus](./src/main/java/com/letsfaceittogether/screens) | Explore the emotion-themed levels and world selection screens. |
| [Interactive objects](./src/main/java/com/letsfaceittogether/objects) | See how switches, moving platforms, and hazards work. |
| [Level builder](./tools/level_builder.html) | Browser-based tool for editing level layouts. |
| [Level previews](./level_previews) | Browse the layouts outside the game. |

## Run on macOS

With Java 17 and Gradle installed, run `gradle run` from this folder. The Gradle build launches the LibGDX desktop application with the macOS first-thread JVM option.
